AvtoTest · Политика конфиденциальности

Как используются ваши данные

Дата вступления в силу: 23 сентября 2026 г.  ·  Приложение: AvtoTest (Android, uz.avtotest.avtotest_mobile)

01 Общие сведения

AvtoTest — бесплатное мобильное приложение для подготовки к экзамену на водительское удостоверение по правилам дорожного движения Узбекистана. На этой странице объясняется, какие данные собираются при использовании приложения, как они используются и с кем передаются.

Используя приложение, вы соглашаетесь с условиями настоящей политики.

Приложение не собирает платёжные данные, номер телефона или паспортные данные. Вход через Google необязателен — всеми функциями тестирования можно пользоваться без входа в аккаунт, в этом случае результаты сохраняются только на вашем устройстве.

03 Сторонние сервисы

Приложение использует следующие сервисы Google, у каждого из которых своя политика конфиденциальности:

  • Firebase Authentication (Google Sign-In) — для входа в аккаунт.
  • Cloud Firestore — для хранения результатов тестов в облаке (только для авторизованных пользователей).
  • Google AdMob — для показа рекламы внутри приложения; обрабатывает рекламный идентификатор и общие (неперсонализирующие вас) данные об устройстве.

Через эти сервисы ваши данные могут обрабатываться компанией Google LLC в соответствии с её собственной Политикой конфиденциальности.

04 Хранение данных и безопасность

Синхронизированные в облако данные хранятся на серверах Google Cloud Firestore с использованием отраслевых стандартов безопасности. Доступ к своим данным имеете только вы через свой аккаунт. Данные, сохранённые локально (без входа в аккаунт), остаются только на вашем устройстве и удаляются при удалении приложения.

05 Ваши права

  • Запрос на удаление — вы можете запросить удаление своего аккаунта и всех результатов в облаке, написав на email ниже; запрос обрабатывается в течение 30 дней.
  • Выход из аккаунта — вы можете выйти из аккаунта в любой момент через меню профиля в приложении.
  • Ограничение персонализации рекламы — вы можете отключить персонализированную рекламу в настройках устройства: Настройки → Google → Реклама.

06 Удаление аккаунта и данных

Приложение AvtoTest (разработчик: Turgunov Sobirjon) позволяет любому вошедшему в аккаунт пользователю запросить полное удаление своего аккаунта и связанных с ним данных.

Как запросить удаление:

  • Шаг 1. Напишите письмо на адрес sobir_0990@mail.ru с темой «Удаление аккаунта AvtoTest», указав email, использованный при входе через Google.
  • Шаг 2. В течение 30 дней ваш аккаунт и все связанные с ним данные будут удалены из Firebase Authentication и Cloud Firestore.
  • Шаг 3. Вы получите письмо-подтверждение на тот же email, когда удаление будет завершено.

07 Конфиденциальность детей

Приложение предназначено для широкой аудитории и сознательно не собирает персональные данные детей младше 13 лет. Рекламный контент ограничен уровнем «Общая аудитория (G)».

08 Изменения в политике

Настоящая политика конфиденциальности может периодически обновляться. О существенных изменениях будет сообщено внутри приложения. Актуальная версия всегда публикуется на этой странице.
